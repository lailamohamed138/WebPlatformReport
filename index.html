المقدمه

من اهم الادوات المستخدمه لبناء المواقع الحديثه ومسؤله عن تصميم المواقع وتساعدنا علي تغيير الوان الخلفيه واختيار خطوط جميله

اهميه CSS

تعتبر لغة CSS مسؤولة عن تحويل الصفحة من مجرد نصوص عادية إلى تصميم جميل ومنظم ونستطيع من خلالها التحكم في الألوان والخلفيات وأنواع الخطوط مما يجعل شكل الموقع جذاب

استخدامات CSS

الاستخدام الوصف
تغيير الألوان التحكم في لون الخلفية والنصوص
تنسيق الخطوط اختيار نوع وحجم الخط

الخاتمة

في الختام تعتبر لغة CSS أساس جمال وتنظيم صفحات الويب ولا يمكن الاستغناء عنها في تصميم المواقع الحديثة.
